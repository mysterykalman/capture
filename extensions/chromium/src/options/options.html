Capture Browser Bridge

Settings for the Chromium extension side of Capture.

Inspect Page shortcut

Chrome manages extension keyboard shortcuts centrally — this extension cannot rebind its own shortcut from this page. Open chrome://extensions/shortcuts to view or change it.

Bookmarks bar privacy

Report browser-window geometry so Capture.app can automatically obscure the bookmarks/favourites bar in captures (Tier 2 of the bookmarks-bar privacy rule — page content is never inspected for this).
